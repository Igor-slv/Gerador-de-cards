# Gerador de textos para cards de Instagram

Protótipo pessoal em HTML e JavaScript que usa IA para sugerir títulos,
textos curtos e legenda para carrosséis de Instagram, a partir de um determinado tema e tom.

## Como funciona
O usuário informa o tema, o tom e a quantidade de cards. A página monta um prompt,
chama a IA e recebe a resposta em JSON, que é exibida na tela.

## O que aprendi
- Engenharia de prompt e resposta estruturada em JSON
- Nos testes, a IA citou leis incerta quando faltavam informações:
  é preciso revisar os fatos antes de publicar
- Após os ajustes foi entregue um texto mais limpo e embasado

## Observação
O recurso de IA só funciona dentro do Claude. Sem ele, a página mostra um aviso.

## Tecnologias
